## Introduction

This repository contains the code used to obtain the results in the study *Transcriptomic analysis of EV miRNA cargo derived from allergen-exposed airway epithelial cells using open-access software*.

The repository contains the following code:

1. Scripts to re-create the workflow: `cd scripts/workflow/*`
2. Scripts to re-create the figures: `cd scripts/figures/*`
3. Supplementary material: `cd supplementary_material`
